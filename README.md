# tryon

Offline garment preview: project a clothing image onto a live webcam
feed or a video, entirely in your browser. No internet, no uploads, no
AI models — the tracker is classical color-region tracking, written
from scratch.

## How it works

1. Pick a source: your webcam, the bundled sample video, or the
   bundled sample photo.
2. Pick a garment: three bundled procedural garments or your own PNG
   (with transparency).
3. **Click the shirt once.** That click seeds a target color; the
   tracker masks every frame by color distance, fits an oriented
   rectangle to the region (centroid + covariance eigen-decomposition),
   and the garment is drawn onto that rectangle each frame, warping and
   moving with it. Tolerance, size, nudge, and opacity are adjustable.

The same algorithm exists twice on purpose: `tryon/tracker.py` is the
reference implementation (unit-tested on synthetic frames, also exposed
at `POST /api/track`), and `www/js/tracker.js` is its realtime twin —
because camera pixels should never leave your machine.

## Quick start

```sh
python3 -m unittest discover -s tests   # 12 tests, offline, loopback only
python3 -m tryon.server 8620           # open http://127.0.0.1:8620
```

Grant camera permission when your browser asks (only if you click
Webcam — the sample video needs nothing).

## Bundled samples

All generated by `tryon/gen_assets.py` (deterministic, no assets
downloaded): three garment PNGs (striped tee, collared shirt, checkered
shirt), a synthetic model photo, and a 15 s sample video of a synthetic
person swaying — a known, uniform shirt color, which is the friendliest
possible input for a color tracker. Regenerating the samples:

```sh
python3 -m tryon.gen_assets
ffmpeg -framerate 6 -i tests/frames/f_%03d.png -c:v libvpx-vp9 \
       -b:v 300k -pix_fmt yuv420p www/samples/model.webm
```

(ffmpeg is a dev-time tool only; nothing in the repo depends on it at
runtime.)

`samples/real/` holds photorealistic test footage instead: one model
photo and a motion-interpolated video (portrait crop, torso-centered)
of a fictional adult in a solid red shirt. Generated with OpenAI Codex's
built-in image generation on a sandbox machine (2026-11-05), so the
person does not exist and the footage is license-clean. The tracker
finds the shirt at tolerance 0.04 targeting rgb(236,14,43).

## Honest limits (v1)

This is a decal, not cloth: no drape simulation, no occlusion handling
(an arm crossing the shirt will still be covered), and the tracker
re-acquires if lighting shifts the shirt color far from your clicked
sample. Real garments beat synthetic ones when the background is not
shirt-colored.

## Layout

- `tryon/tracker.py` — reference tracker (pure function)
- `tryon/gen_assets.py` — procedural garments + synthetic model
- `tryon/server.py` — static + validating API (`/api/garments`,
  `/api/track`)
- `www/` — the client: `js/tracker.js` (twin), `js/main.js` (sources,
  garment picker, overlay loop)
